# Support

This repository is a research software MVP, not a clinical or production decision system.

For reproducible bug reports, include the software version, operating system, Python version, command, synthetic input fixture, expected behavior, observed behavior, and relevant traceback. Use the repository issue tracker after the project is published. Until then, contact Samuel Montalvo at smontal@stanford.edu.

Do not submit participant-level data, protected health information, credentials, or restricted repository files in support requests.
