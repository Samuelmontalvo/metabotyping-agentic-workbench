# MW - MoTrPAC Similarity Table

Source scope: local cached repository snapshot only. I used `data/live/mw_human_candidates.csv`,
the curated live cards in `data/live/publications.csv` and `data/live/repository_records.csv`,
and the existing MoTrPAC alignment report in `reports_live/motrpac_alignment_report.md`.

Important evidence rule: the MW candidate snapshot is title-level for most studies. Only ST004303 and
ST003807 have curated repository cards in this repository. For the other MW study numbers below,
similarity is a triage estimate that needs source metadata, sample matrix, timing, and codebook review.

## Exclusions And Cautions

- I did not count "training set" titles as exercise evidence. Example false positives: ST000385 and ST000888.
- I did not count "resistance" in disease/drug contexts as resistance exercise. Example false positives: ST002273 and ST002496.
- I did not count ECHO "First Steps" records as step-count or physical activity evidence; "steps" in those titles is not an activity variable.
- No exact "DHQ" or "Diet History Questionnaire" string was found in the local MW candidate snapshot.
- Do not promote title-level candidates to direct matches until a reviewer confirms blood/plasma/serum matrix, biospecimen timing, assay platform, codebook, and data availability.
